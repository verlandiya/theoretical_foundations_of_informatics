**Автор:** Гончарова Вера Б26-902

## Описание

Консольная программа на Python читает результаты учебного турнира по программированию из файла `input.txt`, проверяет записи, считает итоговые и средние баллы, строит рейтинг, выполняет поиск и фильтрацию, считает статистику и сохраняет отчёт в `tournament_report.txt`.

## Структура

```
lab_02/
├── main.py                  # программа
├── input.txt         # входные данные
├── tournament_report.txt    # итоговый отчёт
└── README.md                # описание работы
```


## Формат входного файла

Каждая непустая строка — одна запись:

```
номер;участник;группа;задача_1;задача_2;задача_3
101;Иванов Иван;ПИ-101;80;75;90
```

Запись корректна, если: ровно шесть полей; номер — положительное целое и не повторяется; имя и группа не пусты; каждый балл — целое число от 0 до 100. Пробелы по краям полей удаляются. Некорректная строка пропускается, а сообщение с номером строки и причиной попадает в отчёт.

## Показатели

- Итоговый балл = сумма баллов за три задачи (максимум 300).
- Средний балл = итоговый / 3, вывод с двумя знаками после запятой.

| Итоговый балл | Категория |
|---|---|
| 240–300 | Отличный результат |
| 180–239 | Хороший результат |
| 120–179 | Удовлетворительный результат |
| меньше 120 | Требуется подготовка |

Отбор проходят участники с итогом не меньше 180, у которых каждая задача не меньше 50.

## Меню

```
1. Показать всех участников
2. Показать общий рейтинг
3. Найти участников по группе
4. Найти участников по части имени
5. Показать участников, прошедших отбор
6. Показать статистику
7. Сохранить отчёт
0. Завершить программу
```

Неизвестный пункт меню не завершает программу.
